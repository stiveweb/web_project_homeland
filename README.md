# De Pátria para Pátria

## Descrição

Projeto responsivo desenvolvido para apresentar a cidade de TripleTen e histórias de pessoas de diferentes lugares do mundo.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media queries
- Metodologia BEM
- Git e GitHub
